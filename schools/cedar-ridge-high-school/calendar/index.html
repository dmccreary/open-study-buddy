    Cedar Ridge High School Calendar, 2026-2027¶

    This calendar is synthetic: every date, class, and teacher is invented for testing the Open Study Buddy kit. The same events exist in three forms, all generated from one source list by scripts/build-school-calendar.py:

    File Used for
    events.json The hand-edited JSON event file the buddy server reads first
    calendar.ics The iCalendar feed the server parses later (time zone America/Chicago)
    this page A readable copy for students and teachers

    Titles follow the TEST: and DUE: convention, so the agent can answer "When is my next test?" and "What is due this week?" by matching the title prefix.

    Icon Category
    🚫 No school
    📝 Test
    📦 Project due
    🎓 Academic milestone
    🎉 School event
    🏈 Sports
