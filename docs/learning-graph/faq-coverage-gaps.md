# FAQ Coverage Gaps

The FAQ covers 230 of the 326 learning-graph concepts (70.6%). This page lists the 96 concepts it does not yet name, ranked by **Concept Impact Score (CIS)**, the number of concepts that depend on each one directly or indirectly. Coverage was measured by matching each concept label against the question and answer text, so a concept explained in other words may be listed here even though an answer touches it.

Gaps were generated on 2026-10-27 alongside [the FAQ](../faq.md) and the [FAQ Quality Report](faq-quality-report.md).

## Recommendations

1. Add questions for the 5 critical gaps. The RP2350 microcontroller, the flash file system, and the mip package manager could share one hardware-and-tools question, and event parsing could join the calendar answers.
2. Add the medium-priority concepts where they fit an existing answer, such as the Hey Pico phrase in the wake-word answer and the requests library in the Wi-Fi answer. Add new questions only for concepts that need one.
3. Address the low-priority gaps in a future update, after the quizzes are written. Quiz misses will show which of them students actually ask about.
